# Dream Sea — 진행 상황

작성: 2026-09-27

## 완료한 단계
- M0: 사용자 환경에서 Astro 개발 서버와 기본 화면 확인.
- M1: 사용자가 GitHub Pages 첫 배포 성공을 확인.
- 사이트: https://son-dongwoo.github.io/dream-sea/

## 현재 단계: M2 — 첫 탐험 구조
- 허브, Paper Reef, Memory Observatory, Lighthouse, Archive 소스 작성.
- 기본 벡터 아트, 부유 효과, 배경 시차, 네이티브 페이지 전환 CSS 작성.
- `/dream-sea/` 기본 경로는 `src/lib/sea.ts`에서 공통 적용.
- 모든 목적지는 실제 `.astro` 페이지와 HTML 링크로 구성.
- 로컬스토리지 저장 실패 시에도 필수 탐색이 동작하도록 스크립트 구성.
- 동작 감소 설정, 키보드 포커스, 모바일 배치 포함.

## 검증 범위
- 동일 마크업/CSS/JS/이미지를 사용한 정적 HTML 검사본을 Chromium에서 확인.
- 1440px / 390px / 320px 폭에서 가로 넘침 검사.
- 움직임 토글, OS 모션 감소, 키보드 포커스, 배경 시차 확인.
- 로컬 링크와 자산 경로 정적 검증.
- 원격 패키지 설치가 불가능하여 Astro 컴파일 및 빌드는 실행하지 못함.
- 브라우저 실제 페이지 이동과 실제 GitHub 배포는 사용자 환경에서 확인 필요.
- 정적 검사본에서는 로컬스토리지 영속성을 검증하지 않음.

## 다음 단계: M3
